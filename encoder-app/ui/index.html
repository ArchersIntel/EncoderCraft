            Connect to EncoderCraft Server

            Servers run encraft-d and are reached through an SSH tunnel. Nothing is exposed on the server's network. Servers encode media files; FilmCraft project sequences always render on this PC.

              Deploy EncoderCraft Server

              Needs a Linux x86_64 host with systemd, and root or a sudo-capable user. FFmpeg is installed if missing.

              Used for this deployment only and never saved. Leave blank for root or passwordless sudo.

              Jobs can only read and write beneath these. Mount SMB/NFS shares under one of them.

              Verify the server's identity

              The server presented this SSH host key. Compare it with the fingerprint on the machine (ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub) before continuing.
